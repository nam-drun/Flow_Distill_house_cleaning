# Why care?
Ok first of all, we try to reproduce state-of-the-art Flow Matching/Diffusion in image generation. Not by the exact method they use, but by what they could achieve (i.e., could generate clean image even with 4-8 sampling steps). To understand how difficult this is, note that original Diffusion takes 1000 sampling steps to generate clean images. And even latest Flow Matching/Diffusion still takes 50 sampling steps. Furthermore, the closer you get to 1 sampling step, the quicker the quality worsen. 

To save compute but not compromising the method, we decide to simplify the problem itself using toy data distribution. This means we can't actually visually inspect the generated image. So we need a quality metric that we can reliably trust. In general, a good metric is the one that identifies trends that matches with common senses. For example, in the FID [Flow + FD loss](https://arxiv.org/abs/2604.28190) paper shown that a 1-sampling step post-trained Flow can outperform a pretrained Flow in 50-sampling steps, which isn't common sense. Not just because this is completely unheard of before, but when you actually look at the generated image, it doesn't look like a generative model with 0.89 FID, but rather it still looks like generative model with 2-2.5 FID. So we test the same method in our experiment, FID still says Flow + FD loss could beat pretrained Flow; but Wasserstein-2 says otherwise. Note, the naive Wasserstein-2 isn't perfect either (there's a reason people not using it for image generation). And we are not exception, we have to fix it a lot before it identifies trends that matches with common senses in Flow Matching. But even so, we think that a large reason why our Wasserstein-2 metric works is because the ambient space is $`\mathbb R^{16 \times 16 \times 3}`$. If it had been $`\mathbb R^{256 \times 256 \times 3}`$, then no matter what fix we do, Wasserstein-2 wouldn't work. 

So, here are the trends that our modified Wasserstein-2 manages to identify:
1. Flow + Distillation is superior than Flow + FD loss (at least in 3D generation). We don't include 3D generation result here because we already included in our upcoming CVPR paper.
2. Flow + Distillation with 6 sampling steps is near identical quality as pretrained Flow quality with 250 sampling steps (only $`~0.06`$ difference). This matches the common sense about the current SOTA in Flow Matching. You can see this in the screenshot below
3. Flow + Distillation + FD loss can outperform Flow + Distillation in 2 sampling steps. Even with 2 sampling steps, Flow + Distillation + FD loss with 2 sampling steps is only $`~0.60`$ difference from pretrained Flow with 250 sampling steps. You can see this with `factorial-fd-stage2.csv`
